# Code of Conduct

## Our standards

This is a personal learning repository shared publicly for reference. Anyone
interacting with it - through issues, pull requests or discussions - is expected
to:

- Be respectful and constructive in all communications
- Provide helpful and specific feedback rather than vague criticism
- Assume good faith when something looks unusual

## Unacceptable behaviour

- Harassment, abuse or personal attacks of any kind
- Spam or off-topic promotion
- Sharing anyone's private information without consent

## Enforcement

If you experience or witness unacceptable behaviour, contact me at
contact@isaacadjei.me or via https://isaacadjei.me/contact. I will review
reports and take appropriate action, including removing comments or blocking
users if necessary.

## Scope

This code of conduct applies to all interactions within this repository on
GitHub.
